# Automatidata Capstone

Exploratory data analysis and statistical testing project completed as part of Google's Advanced Data Analytics Professional Certificate (Coursera).

## Project Overview
This is a practice capstone built around a fictional consulting scenario: working with **Automatidata**, a company hired by the **New York City Taxi and Limousine Commission (TLC)** to analyze their trip record data.

## What's Included
- Data structuring and cleaning of the NYC TLC taxi dataset
- Exploratory Data Analysis (EDA) using Python (pandas, matplotlib, seaborn)
  - Box plots and histograms of trip distance, total amount, and tip amount
  - Tip analysis by vendor and passenger count
  - Monthly and daily trends in rides and revenue
  - Mean trip distance by drop-off location
- Statistical hypothesis testing: a two-sample t-test comparing fare amounts for credit card vs. cash payments (5% significance level)
- A Tableau visualization designed for accessibility (built for a non-data-savvy, visually-impaired stakeholder)
- An executive summary communicating key findings

## Tools Used
- Python (pandas, matplotlib, seaborn)
- Jupyter Notebook
- Tableau

## Purpose
This project was completed as a hands-on capstone activity to practice the full data analytics workflow — from cleaning and EDA to statistical testing and stakeholder communication.
